# PROGETA

A modern community-driven platform designed to help ambitious individuals learn, build, connect, and grow.

---

## Overview

PROGETA is built around three core initiatives:

### 🚀 LaunchPad

A structured career acceleration program focused on:

* Industry-ready skills
* Real-world projects
* Mentorship
* Portfolio building
* Career readiness

---

### 👥 InnerCircle

A curated community of:

* Builders
* Founders
* Operators
* Ambitious learners

Designed to provide accountability, networking, mentorship, and growth opportunities.

---

### ⚙️ SelfOS

A personal growth and productivity system helping members:

* Build better habits
* Create personal systems
* Improve focus
* Track progress
* Achieve long-term goals

---

## Installation

### Clone Repository

```bash
git clone <repository-url>
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Application will be available at:

```text
http://localhost:3000
```

---

## Environment Variables

Create a `.env.local` file:

```env
NEXT_PUBLIC_SUPABASE_URL=YOUR_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```
