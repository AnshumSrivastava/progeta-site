# Community Page

**Route**: `/community`

## Purpose
Serves as the intake for the Progeta community ("The Network"). It outlines the process for joining, which is framed as an "Extraction Protocol".

## Key Components
- **The Network**: Hero section emphasizing exclusivity.
- **Extraction Procedure**: 4-step process (Briefing, Proof of Work, Transmission, Extraction).
- **CTA**: Directs users to the `/contact` page to start the questionnaire.
