# Pricing Page

**Route**: `/pricing`

## Purpose
Outlines the investment options for individuals and institutions.

## Key Components
- **Individual Designations**: Three-tier pricing cards (Events, Workshops, Tracks). Uses the `bento-card` class for layout.
- **Institutional Partnerships**: Cards for Colleges and Enterprise/Corporate clients.
- **Animations**: Heavy use of `use:reveal` for scroll-triggered entry animations.
