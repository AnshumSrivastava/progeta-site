# Career Tracks

**Route**: `/tracks`

## Purpose
Showcases the comprehensive career programs (Diploma programs). It features a high-level statistical overview and an interactive pathfinder tool.

## Data Source
- `src/lib/content/jobs.ts`: Contains career track definitions.

## Key Components
- **Header**: "Professional Protocols" with stats (Active Tracks, Weeks, Live Fire %).
- **Pathfinder**: A specialized component (`$lib/ui/components/Pathfinder.svelte`) that allows users to explore different career paths interactively.
